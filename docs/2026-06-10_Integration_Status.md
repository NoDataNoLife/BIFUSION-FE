# 프론트엔드-백엔드 API 연동 현황 리포트

이 문서는 프론트엔드와 백엔드가 서로 데이터를 맞추는 과정(Integration)에서 현재 어디까지 완료되었고, 어떤 부분이 막혀있는지(Blocker)를 한눈에 파악하기 위한 리포트입니다.

---

## 1. 🟢 [완료] 회원 인증 (Auth) 및 프로필

* **구글 소셜 로그인**: JWT 쿠키 기반 연동 완료. (로그인 후 대시보드 자동 리다이렉트 성공)
* **마이페이지 조회 및 수정**: `GET /users/me`, `PUT /users/me/profile` 연동 성공.
  * *참고사항*: 수정 후 새로고침 시 프로필 이미지가 날아가는 버그는 백엔드 스펙 수정으로 완벽히 해결됨.
* **전문가 인증 신청**: `POST /users/me/expert` 연동 성공.

---

## 2. 🟡 [진행 중] 프로젝트 (Project) 관리

* **내 프로젝트 목록 조회**: 완료. (비공개 필터링은 프론트엔드 임시 처리 중)
* **프로젝트 생성**: 완료.
* **프로젝트 설정 수정**: 완료. (`PUT /projects/{projectId}`)
* **🚨 블로커(Blocker)**: 
  * 프로젝트 삭제 API가 백엔드에 부재하여 프론트엔드 화면의 "삭제" 버튼이 아직 장식입니다.
  * "나에게 온 초대장 목록" 조회 API가 없어 "수락/거절" 기능을 완성하지 못하고 있습니다.

---

## 3. 🔴 [미완료] 커뮤니티 (Community)

이번 스프린트의 핵심 타겟입니다! 백엔드에서 신규 API를 개발해 주셨으므로, 즉시 연동을 시작할 예정입니다.

* **팀원 모집**: (백엔드 완료) 목록 조회, 상세 조회 프론트엔드 연동 작업 대기 중.
* **전문가 QnA**: (백엔드 완료) 상세 조회, 답변 작성 기능 연동 대기 중.
* **데이터셋 공유**: 백엔드 파일 구조(단일 zip vs 다중 파일) 기획 합의 후 진행 예정.

---

## 4. 연동 시 가장 중요한 원칙 (규칙)

1. **에러가 나면 Network 탭부터 볼 것**: 프론트엔드 코드를 의심하기 전에 F12를 눌러 `Network` 탭에서 백엔드에게 보낸 데이터(Payload)가 정확한지, 응답(Response) 코드가 200인지 400인지부터 확인하세요.
2. **DTO 이름 맞추기**: 백엔드의 JSON Key(`bannerImageUrl`)와 프론트엔드의 상태 이름(`coverImage`)이 다르면 반드시 프론트에서 맵핑(Mapping) 작업을 거쳐야 합니다.
