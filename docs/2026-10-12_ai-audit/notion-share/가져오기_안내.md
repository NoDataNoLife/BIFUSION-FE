# 노션에 가져오기

## 권장: 문서와 구조 그림을 함께 가져오기

1. 노션 데스크톱 또는 웹에서 **설정 → 가져오기**를 엽니다.
2. ZIP을 페이지로 변환하는 항목(**Convert Zip to pages**)을 선택합니다.
3. **BIFUSION_AI_Notion_Import.zip**을 업로드합니다.
4. 만들어진 팀 공유 페이지에서 구조 그림 2개와 표가 보이는지 확인합니다.
5. 원하는 팀 공간으로 페이지를 이동하고 공유 권한을 설정합니다.

ZIP에는 짧은 요약 페이지와 상세 설명 페이지, 이미지 두 개가 들어 있습니다. 가져온 뒤 상세 설명을 요약 페이지 아래로 옮기고 더보기 링크를 해당 노션 페이지로 연결하면 됩니다. 같은 내용을 중복 페이지로 만들지 않도록 Markdown은 ZIP에 넣지 않았습니다. 가져오기는 실제 노션 환경에서 아직 시험하지 않았습니다.

## 내용만 직접 옮길 때

- **BIFUSION_AI_팀공유.md**를 Text & Markdown으로 가져오거나 내용을 복사해 사용합니다.
- 이미지가 함께 들어오지 않으면 assets 폴더의 PNG 두 개를 해당 위치에 올립니다.
- 로컬에서 먼저 읽으려면 **BIFUSION_AI_팀공유.html**을 엽니다.

## 자료 구성

첫 페이지는 구조 그림·현재 상태·우선 작업·결정 사항·완료 기준만 담습니다. 파라미터와 API, 용어의 자세한 설명은 별도 상세 페이지에 보존했습니다.

기존 README.md, ARCHITECTURE.md, BACKEND_REQUEST.md, RUNPOD.md는 수정하지 않았습니다. 통합본은 2026-10-12에 조사한 구현 상태를 정리한 자료이며, 실제 GPU 시험 완료 보고가 아닙니다.

가져오기 방법 근거: [Notion 공식 안내](https://www.notion.com/help/import-data-into-notion). 가져온 뒤 표·체크리스트와 이미지 표시, 팀 공유 권한을 확인하세요.
