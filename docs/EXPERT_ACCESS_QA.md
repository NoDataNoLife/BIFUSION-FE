# 전문가 인증 안내 QA

기준: PR #64 병합 커밋 `fa88b84`. 확인일: 2026-10-22.

## 동작

- 메뉴는 유지한다. `/users/me.expertStatus`가 `APPROVED`인 경우에만 실제 전문가 대시보드를 마운트한다.
- `NONE`/미제공: 인증 안내와 신청 버튼. `PENDING`: 심사 중 안내와 상태 확인 버튼. `REJECTED`: 서류 확인·재신청 버튼.
- 배경은 실제 검수 정보가 없는 정적인 레이아웃이며 블러 처리한다. 접근성 트리와 키보드 탐색에서도 제외한다.
- 버튼은 `/dashboard/profile?settings=verification`로 이동해 기존 전문가 인증 설정 탭을 바로 연다.
- 상태 새로고침은 기존 `/users/me`만 호출한다. 승인되면 실제 대시보드가 마운트되어 성과·검수 목록을 조회한다.
- 예전 `isExpert` 값이 남아 있어도 `expertStatus`가 미승인인 경우 안내 화면을 표시한다.
- 실제 접근 권한은 BE의 기존 검증으로 보호한다. 추가 API는 필요하지 않다.

## 검증

- 프로덕션 빌드 통과, 테스트 22개 통과, 전문가 페이지·안내 카드 ESLint 통과.
- 회귀 검사: 미인증 화면에서 기존 전역 스토어의 검수 정보·403 오류가 노출되지 않음. 심사 중·반려 상태와 신청 링크 확인.
- 로컬 QA 서버에서 미신청·심사 중 사용자의 `/experts/*` 호출 0건 확인.
- 신청 버튼 클릭 후 실제 기존 신청 탭이 열리는 것을 확인.
- 서버 상태를 승인으로 바꾼 뒤 상태 새로고침으로 대시보드 진입 확인. 승인 후 성과·목록 API 호출 확인.
- 데스크톱 1440px, 모바일 390px, 라이트·다크 모드 확인. 모바일 문서 가로 넘침 없음.

로컬 QA는 임시 응답으로 수행했다. 배포 후 실제 계정의 미신청/심사 중/반려/승인 상태와 신청 제출 흐름을 확인한다.
