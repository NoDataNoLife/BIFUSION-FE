# 프론트 연동 현황 · 2026-10-26

## 이번 변경

| 항목 | 구현 내용 | 실제 연동 상태 |
|---|---|---|
| 메인 로고 | 펼친/접힌 사이드바 홈 이동, 모바일 메뉴 닫기 | 코드 완료 |
| 내가 요청한 검수 | 목록·검색·필터·요청 상세·승인 의견·반려 사유, 선택형 예시 화면 | 요청자 목록·상세 API 대기 |
| 알림 | 팝업과 기록의 조회·상태·안읽음 건수 분리, 영구 삭제 확인 및 전체 삭제 | 새 팝업 GET 경로가 없으면 기존 조회로 호환 |
| 초대 권한 | MEMBER 기본, MANAGER에게 관리자 선택, role 전송, 재발송 권한 안내 | MEMBER 사용 가능. 관리자 선택은 BE 배포 확인 후 활성화 |
| 레시피 별점 | 목록·상세·댓글에 표시되는 점수 제거, 별점 없는 댓글 요청 준비 | 입력 제거는 BE의 rating 필수 검증 해제 후 활성화 |
| 레시피 이미지 | 선택·미리보기·제거 UI, 형식·크기 확인, object URL 해제 | 업로드 API 대기. 이미지가 선택되어 있으면 등록을 막고 제거 안내 |
| 전문가 만족도 | API 평균 표시 유지, 평가 없을 때 /5.0 표시 제거 | 평균 조회는 실제 DB 집계. 평가 저장 경로는 확인 필요 |

현재 검수 목록과 이미지 기능은 화면 준비 단계입니다. 실제 내역이나 업로드 성공으로 표시하지 않습니다.

## 서버 반영 후 켤 항목

Vite 빌드 환경변수이며 변경 후 FE 재빌드·배포가 필요합니다. 기본값은 모두 false입니다.

| 환경변수 | 켜기 전 확인 | 켜면 바뀌는 것 |
|---|---|---|
| `VITE_INVITATION_ROLES_ENABLED=true` | 초대 요청의 role 저장, 수락 시 적용, MANAGER 초대 권한 제한 및 재발송 갱신이 배포됐는지 확인 | 관리자에게 MANAGER 선택 제공. 응답 전 재발송 권한 변경 안내 |
| `VITE_COMMENT_ONLY_REVIEWS_ENABLED=true` | 최상위 댓글 POST·PUT이 rating 없이 성공하는지 확인 | 작성·수정 별점 입력 제거, rating을 요청에서 제외. 댓글·답글 유지 |

별점 필수 서버에서 입력을 숨기고 임의의 점수를 보내지 않습니다. 기본 배포는 기존 점수 입력으로 등록 기능을 유지합니다.

## BE에 확인할 내용

| 항목 | 확인 / 요청 |
|---|---|
| 검수 요청자 목록 | [화면 및 API 협의 표](REQUESTED_INSPECTIONS_API.md) 기준으로 경로·응답 확정 |
| 검수 식별자 | inspectionRequestId(신청)와 inspectionId(전문가 배정)가 다름. 요청자 상세에는 어떤 ID를 사용할지 명시 |
| 초대 수락·거절 | 알림에 projectId, invitationId, 현재 상태 및 부여 role 제공 또는 받은 초대 조회 API 필요. 기존 버튼은 계속 준비 중 상태 |
| 선택 이미지 | 현재 등록 JSON에는 이미지 필드가 없고 레시피 수정 API도 배포 Swagger에 없음. 업로드 방식·필드·수정 API 확정 필요 |
| 별점 제거 | 현재 배포 서버는 최상위 댓글 rating 필수. POST·PUT의 필수 검증을 제거해야 입력까지 없앨 수 있음 |
| 전문가 만족도 | `ExpertTask.satisfaction` 평균 조회는 있음. 확인한 origin/main에서 평가 제출 API·저장 경로는 찾지 못함 |
| 검수 대상 카드 | 현재 배포된 전문가 목록은 projectName 중심이고 AUGMENTED_DATA만 지원. 대상 이름·유형·이미지 및 레시피/원본 지원이 배포되면 연결 필요 |

## 배포 계약 확인 근거

2026-10-26 실서버 `/api-docs`와 BE origin/main을 확인한 결과입니다. 팀원이 전달한 변경이 실서버에는 아직 모두 반영되지 않았습니다.

| 현재 확인된 계약 | 이번 처리 |
|---|---|
| GET /notifications/popup 없음, 기존 GET /notifications는 소프트 삭제 제외 | 팝업은 새 경로를 먼저 호출하고 404/405에만 기존 경로로 재시도. 401/403/5xx는 오류로 표시 |
| ProjectInvitationRequest는 email만 명시 | MEMBER 호환 유지, MANAGER는 서버 배포 전 비활성 |
| RecipeReviewRequest/UpdateRequest는 최상위 rating 필수 | 점수 표시 제거, 입력·전송은 전환 설정으로 보호 |
| 요청자 검수 목록 API 없음 | 임의 경로를 호출하지 않고 명시적인 예시 화면 제공 |

## 실제 QA

- [ ] 검수 예시 화면: 세 유형·네 상태·검색 조합·결과 상세·키보드·모바일
- [ ] 팝업에서 숨긴 알림: 팝업에서는 사라지고 전체 기록에 유지
- [ ] 팝업/전체 기록을 번갈아 열어 목록·페이지·뱃지가 섞이지 않는지 확인
- [ ] 단건/전체 영구 삭제 취소·확정, 숨긴 알림까지 전체 삭제되는지 확인
- [ ] 관리자 초대: BE 반영 후 초대 → 수락 → 실제 권한 확인, 재발송 변경 확인
- [ ] 별점 없는 댓글: BE 반영 후 작성·수정·답글·삭제 확인
- [ ] 이미지 선택·제거·잘못된 형식·10MB 초과·이미지 없는 기존 등록 확인
- [ ] 실제 API 연결 후 검수 신청 → 전문가 검수 → 요청자 결과 조회 확인

이미지의 PNG/JPG/WebP·10MB 제한은 현재 FE 미리보기 기준이며, 실제 업로드 제한은 BE 계약에 맞춰 조정합니다.
