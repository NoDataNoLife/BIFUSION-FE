# 포크한 레시피로 내 레시피 만들기

| 진입 | 동작 |
|---|---|
| 내 자산 → Fork한 레시피 카드 | **내 레시피로 만들기**로 작성 화면 열기 |
| Fork한 레시피 상세 | 상단의 같은 버튼으로 내용과 설정 불러오기 |
| 내 자산 → 새 자산 → 새 레시피 | **포크한 레시피 불러오기**에서 저장한 목록 선택 |

## 불러오기 / 등록

| API | 사용 내용 |
|---|---|
| GET `/api/v1/assets/recipes?type=FORKED&page=0&size=6` | 본인이 저장한 레시피를 페이지 단위로 선택 |
| GET `/api/v1/community/recipes/{recipeId}` | 선택한 레시피의 본문·특징·추천 용도·실제 생성 설정 조회 |
| POST `/api/v1/community/recipes` | 수정한 내용으로 새 레시피 등록. 내 자산에서는 `isPublic: false` |

- 제목·요약·본문·특징·추천 용도·모델·스텝·샘플러·CFG·시드·해상도·배치 크기를 가져옵니다.
- 설정에 없는 값은 비워 두고 입력하도록 합니다. 0, 사용자 정의 샘플러·해상도, 배치 크기도 유지합니다.
- 작성 중 내용을 다른 레시피로 바꿀 때 확인합니다. 로딩 중 수정·등록과 중복 요청을 막고, 실패 시 기존 입력을 유지합니다.
- 원본은 수정하지 않습니다. 검수 인증·작성자·통계·이미지 파일을 복사하지 않습니다.
- 저장 성공 후 내 자산의 **내 레시피** 탭을 갱신합니다. 데이터셋 등록 후 목록 갱신도 유지합니다.

## 분류 기준 주의

BE origin/main의 MINE은 `forkedFrom IS NULL`, FORKED는 `forkedFrom IS NOT NULL` 기준입니다.
따라서 이 기능은 내용을 편집해 **내 레시피로 새로 등록**하므로 `forkedFromId`를 보내지 않습니다.
이 필드를 보내면 새 항목도 다시 FORKED로 분류되며 원본 forkCount가 증가합니다.
새 항목의 출처를 별도로 보존하려면 MINE 분류와 독립적인 출처 필드를 BE와 협의해야 합니다.

마이페이지에서 저장한 포크 레시피 제외는 BE 담당자가 별도 반영 예정입니다. 이 FE 작업은 활동 목록을 임의 필터링하지 않습니다.

## 확인할 것

- [ ] 카드 / 상세 / 새 레시피의 세 경로에서 불러오기
- [ ] 여러 페이지 중 저장한 레시피 선택
- [ ] 기존 내용 덮어쓰기 확인 취소 / 동의
- [ ] 조회 실패·삭제된 레시피·필수 설정 누락 시 안내
- [ ] 수정 후 저장하면 내 레시피에 생성되고 원본은 그대로인지 확인
- [ ] 제목·본문·생성 설정·배치 크기·공개 범위 확인
- [ ] 내 자산 데이터셋 등록 후 목록 갱신 회귀 확인

자동 테스트는 설정 변환·숫자 검증·누락 값·등록 본문의 공개 범위와 출처 ID 제외를 검사합니다. 실제 계정의 브라우저 QA는 별도입니다.
