# 리뷰 별점 응답 보완 요청

레시피 리뷰 작성·수정 API는 rating(1~5)을 받지만, 확인한 로컬 BE의 RecipeReviewResponse에는 rating이 없습니다.

- GET /api/v1/community/recipes/{recipeId}/reviews 의 최상위 리뷰에 저장된 rating 반환
- 답글은 rating: null (또는 필드 생략)
- 리뷰 작성·수정 응답에도 동일한 필드 반환
- 상세 평균 평점과 목록의 개별 별점이 등록·수정·삭제 후 함께 갱신되는지 확인

FE는 rating이 내려오면 별점으로 표시하고 수정 폼에 기존 값을 채웁니다. 누락된 경우에는 '평점 정보 없음'을 표시하고, 최상위 리뷰 수정 시 평점을 명시적으로 다시 선택하도록 합니다. 임의의 기존 평점은 표시하지 않습니다.

FE 변경: 브라우저 prompt를 인라인 본문/답글 폼으로 대체, 별 아이콘 선택 및 읽기 전용 표시 적용.
실서버 응답과 실제 등록·수정·답글 저장은 배포 후 확인이 필요합니다.
