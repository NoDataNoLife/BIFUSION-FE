# 내가 요청한 검수 목록 · API 협의

본인이 신청한 검수의 진행 상황과 결과를 보는 화면입니다. **FE 화면은 구현됐으며, 실제 API 연결은 대기 중입니다.**

## 화면 구성

| 항목 | 내용 |
|---|---|
| 진입 | 사이드바 / 내 자산 → **내가 요청한 검수** |
| 화면 경로 | `/dashboard/inspections` |
| 검수 대상 | 레시피 · 원본 데이터셋 · 증강 데이터셋 |
| 목록 | 대상 이미지·이름·유형, 요청일, 담당 전문가, 진행 상태 |
| 검색·필터 | 대상 이름 검색 / 대상 유형 / 검수 상태 |
| 상세·결과 | 요청 정보, 완료일, 전문가 의견 또는 반려 사유 |
| 미리보기 | **예시 화면 보기**로 확인 가능. 실제 계정 내역과 구분해 표시 |

## 필요한 API

아래 경로와 필드는 **제안**입니다. 기존 API로 제공 가능하면 그에 맞춰 FE를 연결하겠습니다.

| 용도 | 제안 / 확인할 내용 |
|---|---|
| 내가 요청한 목록 | `GET /api/v1/inspections/me/requests` |
| 요청 상세·결과 | 기존 `GET /api/v1/inspections/{inspectionId}`를 요청자도 조회 가능한지 확인. 불가능하면 요청자용 상세 API 필요 |
| 목록 조건 | `targetType`, `status`, `keyword`, `page`(0부터), `size` |
| 정렬·페이지 | 요청일 최신순, 검색·필터 적용 후 서버 페이지네이션 |
| 접근 권한 | 로그인한 본인이 요청한 내역만 조회 |

※ `/experts/me/tasks`는 전문가에게 배정된 목록이므로 이 화면과 용도가 다릅니다.

## 필요한 응답 정보

필드명은 예시이며, 목록과 상세 중 어디에 제공할지는 BE 구조에 맞춰 조정 가능합니다.

| 정보 | 제안 필드 | 비고 |
|---|---|---|
| 검수 ID | `inspectionId` | 상세 조회에 사용할 ID |
| 대상 정보 | `target.type`, `target.id`, `target.name` | 유형: `RECIPE` / `UPLOADED_DATA` / `AUGMENTED_DATA` |
| 대표 이미지 | `target.imageUrl` | 없으면 `null`, FE에서 대체 이미지 표시 |
| 진행 상태 | `status` | 대기 / 진행 중 / 승인 / 반려 구분 |
| 요청일·완료일 | `requestedAt`, `completedAt` | 시간대 포함 ISO 8601 권장. 완료 전 완료일은 `null` |
| 담당 전문가 | `expert.nickname` | 미배정이면 `expert: null` |
| 최종 의견·반려 사유 | `result.comment` | 결과 확정 전 `result: null` |
| 페이지 정보 | `content`, `totalElements`, `totalPages`, `pageNumber` | 기존 공통 응답 형식 사용 가능 |
| 상태별 전체 건수 | `statusCounts` | 상단 요약 카드용. 현재 페이지 건수와 구분 |

## 확정 부탁드릴 사항

| 확인 사항 | FE 제안 |
|---|---|
| 상태 표현 | `PENDING` / `IN_PROGRESS` / `APPROVED` / `REJECTED`. 기존 `COMPLETED + reviewResult` 형식도 FE에서 변환 가능 |
| 대상 ID | 증강 데이터셋의 `target.id`가 데이터셋 ID인지 AugmentationConfig ID인지 명시 |
| 검수 ID | 상세 조회 ID와 전문가 작업 ID가 다르면 구분 |
| 상태별 건수 범위 | 검색·필터와 무관한 본인의 전체 요청 건수 제안 |
| 삭제된 대상 | 검수 이력 유지 여부와 대상 이름·이미지 처리 기준 확인 |

## 후속 작업

| 담당 | 할 일 | 상태 |
|---|---|---|
| FE | 목록·필터·상세 화면, 예시 미리보기 | 코드 구현 완료 |
| BE·FE | API 경로·필드·상태 및 위 확인 사항 확정 | 협의 필요 |
| BE | 요청자 목록·상세 API 제공 및 권한 검증 | 제공 확인 필요 |
| FE | 실제 API, 페이지네이션, 로딩·오류·빈 목록 연결 및 예시 모드 정리 | 연결 대기 |
| BE·FE | 신청 → 목록 확인 → 검수 → 승인·반려 결과 확인 | 연동 후 테스트 |

화면을 공유할 때에는 **예시 화면 보기 안내가 보이는 목록 1장**, **승인 의견 또는 반려 사유가 보이는 상세 1장**을 첨부하면 됩니다.
