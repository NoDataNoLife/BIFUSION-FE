# 기존 디자인 복원 QA

기준: PR #63 병합 후 main `6db3a03`. 디자인 비교 기준: PR #62 병합 커밋 `3c0971c`.
검사일: 2026-10-22.

## 변경 범위

- 대시보드: 기존 빠른 실행 카드·프로젝트 표지·리소스 카드 배치 복원. 프로젝트/작업 수/포인트는 기존 API 사용.
- 자산: 기존 카드·이미지 영역·평점/통계·탭 디자인 복원. 실제 응답 필드와 페이지 이동 유지.
- 커뮤니티: 기존 Research Hub 검색·탭·레시피 카드·Q&A/모집/데이터셋 행 복원. 검색·정렬·상세 URL 유지.
- 레시피: 이미지/작성자/통계의 좌우 배치와 개요/설정/리뷰 탭 복원. 리뷰 등록·수정·답글·삭제의 기존 API 동작 유지.
- 데이터셋: 정보 카드·파일 정보·활용 가이드·사이드 정보/검증 카드 복원. 다운로드/수정/삭제 유지.
- 활동: 날짜별 타임라인 복원. 현재 API가 제공하는 본인 커뮤니티 활동 종류에 맞춰 필터 표시.
- 모바일: 768px 미만에서 메뉴를 대화상자로 열어 본문 너비 확보. 기본 dialog의 포커스/닫기 동작 사용. 메뉴 선택 시 닫고 데스크톱 크기 전환 시 닫음.
- 표지 미등록은 중립적인 아이콘과 배경으로 표현. 실패/빈 목록/미집계 상태를 구분.

## 로컬 검증 결과

제품 코드에 포함되지 않는 로컬 QA 서버의 응답으로 검사했다. 인증·실데이터·S3 다운로드를 포함하는 실서버 통합 검증과는 구분한다.

| 검사 | 결과 |
| --- | --- |
| `npm run build` (TypeScript + Vite) | 통과 |
| `npm test` | 기존 20개 통과 |
| `git diff --check` | 통과 |
| 변경한 TS/TSX 11개 파일 ESLint | 통과 |
| 데스크톱 1440px 대시보드/커뮤니티/자산/상세 | 기존 카드·탭·좌우 배치 확인 |
| 모바일 390px 자산/커뮤니티 | 본문 너비 390px, 문서 가로 넘침 없음 |
| 모바일 탐색 메뉴 | 열기 → 메뉴 선택 → 자동 닫힘 확인 |

| 활동 타임라인 | 활동 카드에서 해당 레시피 상세로 이동 확인 |

## 배포 후 확인할 항목

1. Vercel 배포의 Source가 이번 PR의 병합 커밋인지 확인한 뒤 Google 로그인.
2. 내 프로젝트 배너·작업 수·포인트와 실제 계정 데이터 비교.
3. 자산 4개 탭, 커뮤니티 4개 탭에서 검색·페이지 이동·상세 진입 확인.
4. 본인/타인 권한으로 레시피 리뷰와 데이터셋 수정·다운로드 동작 확인.
5. 모바일 메뉴·라이트/다크 모드·긴 제목 화면 확인.
6. 실제 생성된 증강 데이터 → 학습 → 추론은 배포된 BE/ML 환경에서 별도 E2E 확인.
